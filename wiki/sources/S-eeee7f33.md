# Models Download Stats — Hugging Face Hub documentation

## Що це
Сторінка офіційної документації Hugging Face Hub про те, як рахуються завантаження моделей:
які файли вважаються «query files», як обробляються GGUF і diffusers, і що детальніші журнали
доступні лише власникам організацій через Publisher Analytics. Потрібна всім, хто читає
лічильники завантажень Hub як показник вжитку відкритих моделей. Дати на сторінці немає;
у полі `published` — дата останнього коміту вихідного файлу в `huggingface/hub-docs`
(запит до GitHub API 2026-10-08).

## Чому такий grade
B: офіційна документація постачальника про власний продукт (як працює лічильник). Не
стосується якості чи порівнянь; самі числа завантажень тут не наводяться.
