# Delta Wiki — Про систему (українська версія)

## Що це
Українська версія офіційної публічної вікі-документації системи DELTA
(delta.mil.gov.ua/open-wiki/, без /en/) — окрема сторінка від англомовної
[[S-1d332fef]]. Навігація: «Про систему», «Як отримати доступ (реєстрація)?»,
«Налаштування двофакторної автентифікації», «Типові питання при вході»,
«Відновлення після деактивації», «Згідно-відповідно», «Правила безпеки»,
«Повідомлення про персональні дані», «Умови користування» — окремого розділу
про Mission Control, місії чи 26 типів немає. У розділі «Ключові сервіси»
MISSION CONTROL описано як «координація екіпажів безпілотних систем для
розподілу зон відповідальності та спільного планування місій» (поряд з
DELTA MONITOR, ELEMENT, VEZHA, TARGET HUB). Серед зовнішніх інтеграцій
системи згадані постачальники супутникових знімків, радари, GPS-трекери,
оператори супутників, чат-боти й «інтерфейси обміну даними НАТО» — без деталей
про формати чи API саме для даних місій. Дата останнього оновлення сторінки
на ній не вказана; перевірено футер і навігацію — мітки часу немає.

## Чому такий grade
Офіційна продуктова документація від держоргану-власника системи про власний
продукт (перелік модулів і функцій) — за CLAUDE.md це grade B (документація
про функції), не A (A — для офіційних заяв/релізів і статистики), узгоджено з
[[S-1d332fef]].
