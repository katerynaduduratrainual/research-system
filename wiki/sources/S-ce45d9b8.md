# Evaluating Very Long-Term Conversational Memory of LLM Agents

## Що це
Першоджерело бенчмарку LoCoMo: 50 дуже довгих діалогів (до 35 сесій, ~300
реплік кожен), згенерованих людино-LLM конвеєром і звірених людьми-анотаторами,
з задачами QA, event summarization і multi-modal dialogue generation для
вимірювання довгострокової памʼяті моделей.

## Чому такий grade
Рецензована робота (ACL 2024), первинні дані й методологія побудови датасету,
широко цитується як стандартний бенчмарк для agent-memory (в т.ч. вендорами
типу Letta/Mem0) — A.
