# Create custom subagents - Claude Code Docs

## Що це
Офіційна довідка Claude Code про субагентів: конфігурація, ізоляція контексту,
ліміти паралелізму й глибини спавну, вибір моделі на субагента, maxTurns.

## Чому такий grade
Офіційна документація вендора про власний продукт — авторитетне джерело щодо
задокументованих лімітів і механіки (висока довіра для фактів про ліміти),
але vendor-джерело, не незалежна оцінка ефективності.
