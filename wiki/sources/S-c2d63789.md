# Detecting and Correcting Reference Hallucinations in Commercial LLMs and Deep Research Agents

## Що це
Академічне дослідження (arXiv, квітень 2026) частоти «вигаданих» і
«нерозв'язних» URL-цитат у 10 комерційних моделях/агентах трьох вендорів
(OpenAI, Google, Anthropic), включно з deep-research режимами OpenAI та
Gemini. Методологія: перевірка кожного нерозв'язного URL через Wayback
Machine API — якщо снепшоту немає в жодному часовому штампі, URL
класифікується як вигаданий.
