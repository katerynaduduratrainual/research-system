# Kateryna Chernohorenko: The Mission Control module is now accessible to all DELTA users

## Що це
Офіційний пресреліз Міноборони (27.01.2025, англомовна версія сайту mod.gov.ua)
про відкриття доступу до модуля Mission Control усім користувачам бойової
системи DELTA. Дата підтверджена URL-патерном паралельної публікації
АрміяInform (armyinform.com.ua/2025/01/27/...). Модуль описаний як інструмент
планування: розподіл зон відповідальності, маршрутне планування для екіпажів,
координація завдань у реальному часі для БпЛА; також збирає й аналізує дані
місій, знижує ризик «дружнього вогню». На момент публікації модуль вже
використали понад 300 підрозділів (конкретні назви не вказані).

## Чому такий grade
Офіційний пресреліз Міністерства оборони на власному домені mod.gov.ua про
власну державну систему — первинна офіційна заява органу влади, узгоджено з
grade A для аналогічних пресрелізів mod.gov.ua в цьому ж brief
([[E-B003-8-01]], [[E-B003-8-05]], [[E-B003-8-06]]).
