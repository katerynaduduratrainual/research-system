# Пошук Prozorro: закупівлі ретрансляторів для дронів (2023–2026)

## Що це
Пошуковий API порталу Prozorro (POST `api/search/tenders`, параметр `text`, `page`).
21.10.2026 запити дали 127 («ретранслятор FPV»), 81 («ретранслятор для дронів»), 110
(«ретранслятор БпЛА»), 81 («ретранслятор дрон») збігів; скаут прочитав усі сторінки (234
унікальні закупівлі) і відібрав 166, у назві яких є «ретрансл/репітер» і дроновий термін
(FPV, БпЛА, дрон, безпілотн, квадрокоптер). Поля пошуку: назва, замовник, очікувана
вартість, статус; суми переможців і кількості не отримано (пошук не повертає внутрішній
id для public-api). Дата `published` — дата знімка живого реєстру.

## Чому такий grade
Первинні дані державної системи закупівель. Вибірка неповна: лоти з ретранслятором у
складі ширшої назви («обладнання для БпЛА») не потрапляють; оборонні закупівлі МО
через DOT-Chain Defence і закриті процедури тут не видно. Суми — очікувана вартість, не
ціна договору.
