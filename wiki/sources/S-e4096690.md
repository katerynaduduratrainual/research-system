# Artificial Analysis API Documentation (Free API)

## Що це
Офіційна документація безкоштовного API компанії Artificial Analysis, яка сама вимірює
моделі: ендпоінт LLM (`/api/v2/data/llms/models`) повертає JSON із балами якості
(Intelligence Index та окремі оцінювання), ціною за мільйон токенів і швидкістю; є ендпоінти
для моделей зображень, відео й мовлення. Описано ліміт запитів, вимогу посилання на джерело й
існування окремого комерційного API. Скаут також відкрив сторінку методології
(`artificialanalysis.ai/methodology`). Дати на сторінці немає.
