# Claude Managed Agents overview - Claude Platform Docs

## Що це
Офіційна документація Claude Platform API про Managed Agents — керований
"harness" для довготривалих асинхронних агентних сесій зі scheduled
deployments (cron), окремий від Claude Code CLI/Routines.
