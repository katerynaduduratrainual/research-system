# llama.cpp_bench — DGX Spark report

## Що це
Репозиторій з бенчмарк-скриптами та результатами для NVIDIA DGX Spark (GB10 Grace
Blackwell, 128 GB LPDDR5x, ~273 GB/s), запущеними через llama.cpp: окремі таблиці
prefill (prompt processing) і decode (generation) tok/s для щільних (dense) і
mixture-of-experts (MoE) моделей на різних довжинах контексту, квантизація
Q4_K_M. Дата останнього коміту в файл — 2025-12-05 (підтверджено через
GitHub API `commits?path=dgx_spark/report.md`).

## Чому такий grade
Фактичний прогін бенчмарку конкретною особою (є код, методологія відтворювана),
але не рецензовано, не вендор, автор — GitHub-нік без підтвердженої інституційної
афіліації. За правилами CLAUDE.md такі джерела — C, попри хорошу методологічну
прозорість (код відкритий, можна відтворити).
