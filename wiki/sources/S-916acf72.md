# UN Comtrade public API: імпорт України за кодами HS 850440 і 850760, річні дані 2021–2025

## Що це
Відповідь публічного API бази UN Comtrade (preview) на запит: звітувальник — Україна (804), партнер — світ (0), потік — імпорт, коди 850440 (статичні перетворювачі) і 850760 (літій-іонні акумулятори), періоди 2021–2025 запитувалися окремо параметром `period`. За 2025 рік записів немає. Окремо запитано дзеркальні дані: експорт Китаю (156) в Україну 2024. Дата публікації: API не повертає дати оновлення; JSON, footer і «last updated» відсутні; Wayback для параметризованого API не перевіряли — тому «невідомо».

## Чому такий grade
A: офіційна статистика ООН на основі митних даних країн. Застереження: у записах по Україні `isReported: false`, `isAggregate: true`, `legacyEstimationFlag: 6` — значення агреговані або оцінені Comtrade, а не звітовані Україною напряму; для 2022 не вказано вагу нетто. Коди широкі: 850440 охоплює всі статичні перетворювачі (не лише сонячні інвертори), 850760 — усі Li-ion акумулятори (включно з тяговими, для дронів, електроніки).
