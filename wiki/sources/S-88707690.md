# Prozorro Market API — перелік категорій електронного каталогу

## Що це
Публічний API категорій Prozorro Market: 4377 категорій на 22.10.2026. Скаут переглянув назви й статуси 175 категорій з кодами ДК021 32*, 34*, 35*, 48* (радіо- і телекомобладнання, транспорт/авіа, оборонне, ПЗ). Живі дані; `published` — дата знімка.

## Чому такий grade
Первинні дані державної системи (A). Обмеження: переглянуто лише частину кодів, назви категорій без пошуку за товарами.
