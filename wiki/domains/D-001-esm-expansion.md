# Експансія ESM: керування накопичувачами енергії для бізнесу в Україні

## Чому цей напрям
Слова редактора, 2026-10-06: «Є ось така система вже — esm.everlabs.com. Це вже існуюча,
до того ж наша система. Нюанс в тому, що це поки PoC або ж MVP, який діє суто для нас,
і суто для Deye (система інверторів). Треба зрозуміти, як ми можемо здійснити експансію».

Що таке ESM сьогодні (з продуктової сторінки, [[S-41493f79]]): хмарний сервіс, який
щогодини керує зарядом і розрядом накопичувача бізнес-об'єкта за погодинними цінами
ринку «на добу наперед», через API Deye Cloud, без монтажу; оплата — 18% від економії.
Працює на власному офісі Everlabs з лютого 2026; клієнтів поза компанією поки немає
(редактор, 2026-10-06).

## Межі
- В межах: експансія ESM двома осями (редактор, 2026-10-06): (1) інші бренди гібридних
  інверторів і накопичувачів, окрім Deye; (2) інші сегменти клієнтів, окрім нинішнього
  (бізнес із батареєю від ~50 кВт·год, Deye, погодинний облік). Для цього — ринок
  електроенергії України для споживачів із накопичувачами, гравці, що продають
  керування накопичувачами, регуляторика погодинних тарифів, обліку й агрегації.
- Поза межами: інші країни; зміна типу продукту (VPP/агрегатор, white-label,
  ліцензування алгоритму) — не вісь дослідження, але фіксуємо в шарі 3, якщо
  трапляється; ринки РФ і Білорусі — категорично ні (`docs/context.md`).
- Географія: лише Україна.
- Час: без орієнтовної дати виходу на кандидатів (редактор, 2026-10-06); темп задає
  редактор по ходу.

## Шари

### 1. Основи (`fundamentals`)
Як влаштована галузь, ланцюжок вартості, хто кому платить, масштаб, терміни, технологія.
- **Що знаємо:** wiki порожня по темі (перевірено 2026-10-06: `wiki/topics/` без
  сторінок). Базова лінія — поточний стан самого продукту, з його сторінки (C,
  2026-10, верифікація критиком триває):
  - керує лише Deye через Deye Cloud; інші бренди — «якщо буде попит» [[E-ING-20261006-01]];
  - 18% від економії, без передоплати, без економії — без плати [[E-ING-20261006-02]];
  - передумови: Deye Cloud, батарея від ~50 кВт·год, АСКОЕ, тариф із прив'язкою до РДН [[E-ING-20261006-03]];
  - власний офіс: −21,9% рахунку за лют–лип 2026 (самозаявлено) [[E-ING-20261006-04]];
  - модель для виробничого комплексу ≈37 МВт·год/міс: 0,2 млн ₴/рік зі 100 кВт·год,
    1,06 млн ₴/рік із 500 кВт·год (розрахунок вендора) [[E-ING-20261006-05]];
  - ринкові числа в переказі сторінки, потребують первинних джерел: РДН червень 2026
    5 696 ₴/МВт·год [[E-ING-20261006-06]]; АСКОЕ 30–80 тис. грн, 4–8 тижнів
    [[E-ING-20261006-07]]; погодинний облік обов'язковий від 150 кВт
    [[E-ING-20261006-08]]; спред цін доби 3–6× [[E-ING-20261006-09]];
  - опція арбітражу (продаж у мережу) за наявності договору на відпуск [[E-ING-20261006-10]].
- **Впевненість:** ще не досліджували
- **Черга питань:**
  1. [ ] Як працює ринок електроенергії для бізнес-споживачів України і хто кому платить (РДН, постачальники, ОСР, погодинні тарифи, АСКОЕ)? → B-001 _(походження: лід, вступ)_
  2. [ ] Скільки в Україні бізнес-об'єктів із накопичувачами (особливо ≥ 50 кВт·год), яка динаміка 2022–2026 і які частки брендів інверторів? → B-001 _(походження: редактор — вісь «бренди»)_
  3. [ ] Які сегменти споживачів ставлять накопичувачі й навіщо; хто їм продає обладнання і керування? → B-001 _(походження: редактор — вісь «сегменти»)_
  4. [ ] Терміни й технологія: як керувати інвертором ззовні (хмарні API, Modbus), що дозволяють вендори? → B-001 _(походження: лід, вступ)_
  5. [ ] Що змінилося за 5 років: війна й відключення, ENTSO-E, погодинні тарифи, Кодекс обліку, агрегація, спреди РДН, ціни батарей? → B-001 _(походження: лід, вступ)_
  6. [ ] Де читати: праймери, звіти, відкриті дані (погодинні ціни РДН)? → B-001 _(походження: лід, вступ)_
- **Потрібно від редактора:**
  - Чи можна використати власні дані ESM (телеметрія офісу, бектест на 302 днях,
    розрахунок для виробничого комплексу) як джерело grade B через ingest? Зараз
    сторінка продукту — grade C.
  - Скільки заявок надійшло з сайту і які бренди інверторів у них називали (сайт
    збирає це як міру попиту)?
  - `docs/context.md` каже «активів немає»; ESM із трьома роками погодинних даних,
    LP-планувальником і живою інсталяцією — актив, який впливає на критерій «відповідність».
    Оновити context.md?

### 2. Попит (`demand`)
У кого які проблеми, як їх вирішують сьогодні, за що платять, скільки їх.
- **Що знаємо:** ще нічого; сьогоднішній сегмент ESM — бізнес із батареєю від
  ~50 кВт·год на Deye [[E-ING-20261006-03]].
- **Впевненість:** ще не досліджували
- **Черга питань:**
  1. [ ] Які сегменти бізнесу вже мають батареї ≥ 50 кВт·год (офіси, виробництво, склади, рітейл, агро, медицина, телеком) і чим мотивована купівля: резерв чи економія? _(походження: редактор — вісь «сегменти»)_
  2. [ ] Чи готові ці сегменти переходити на погодинний тариф і що їх стримує (АСКОЕ, ризик, бухгалтерія)? _(походження: лід)_
  3. [ ] Домогосподарства й ОСББ: чи є для них погодинний тариф і економічний сенс керування? _(походження: редактор — вісь «сегменти»)_
  4. [ ] Великі промислові споживачі: чи мають власних енергетиків/EMS і чи купують таке ззовні? _(походження: редактор — вісь «сегменти»)_
- **Потрібно від редактора:** перелік вхідних заявок із сайту за сегментами (якщо є).

### 3. Хто й як заробляє (`models`)
Існуючі бізнес-моделі, ціни, маржа, що з цими бізнесами стало.
- **Що знаємо:** модель ESM — 18% від економії [[E-ING-20261006-02]]; друга можлива
  модель заробітку клієнта — арбітраж із продажем у мережу [[E-ING-20261006-10]].
- **Впевненість:** ще не досліджували
- **Черга питань:**
  1. [ ] Хто в Україні вже продає керування накопичувачами за цінами РДН (інсталятори, постачальники, вендори інверторів, стартапи) і за якими моделями (% економії, підписка, разово)? _(походження: лід)_
  2. [ ] Чи вбудовують вендори інверторів (Deye, Huawei, Victron, SolarEdge, Growatt…) оптимізацію за цінами у власні застосунки і що це означає для окремого сервісу? _(походження: редактор — вісь «бренди»)_
  3. [ ] Чи пропонують постачальники (YASNO, ETG, D.Trading) власні сервіси оптимізації разом із погодинним тарифом? _(походження: лід)_

### 4. Що змінюється (`signals`)
Технологія, регуляторика, гроші, що відкрилося недавно, що закривається.
- **Що знаємо:** за сторінкою ESM, спред цін доби на РДН 3–6×, і вендор сам очікує
  звуження спреду зі зростанням кількості накопичувачів [[E-ING-20261006-09]].
- **Впевненість:** ще не досліджували
- **Черга питань:**
  1. [ ] Динаміка спредів РДН 2023–2026 і прогноз: що буде з економікою моделі, коли накопичувачів стане більше? _(походження: лід)_
  2. [ ] Регуляторні зміни: агрегація/агрегатори, погодинні тарифи для малого бізнесу й населення, net-billing, price caps на РДН? _(походження: лід)_
  3. [ ] Ціни батарей і гібридних інверторів в Україні 2024–2026 і їхній вплив на кількість потенційних клієнтів? _(походження: лід)_
- **Потрібно від редактора:** —

### 5. Вхід і правила (`entry`)
Закупівлі, сертифікація, ліцензії, бар'єри для нового гравця.
- **Що знаємо:** для клієнта без АСКОЕ вхід коштує 30–80 тис. грн і 4–8 тижнів (оцінка
  вендора) [[E-ING-20261006-07]]; від 150 кВт погодинний облік нібито обов'язковий
  [[E-ING-20261006-08]].
- **Впевненість:** ще не досліджували
- **Черга питань:**
  1. [ ] Які бренди інверторів мають хмарні або локальні API для керування розкладом заряду (Huawei FusionSolar, SolarEdge, Victron VRM, Growatt, Solis/Solarman, SMA, Fronius, Sungrow) і на яких умовах (партнерські програми, OAuth, ліміти)? _(походження: редактор — вісь «бренди»)_
  2. [ ] Чи потрібна ліцензія, реєстрація чи статус (агрегатор, ППКО) для керування чужим обладнанням і доступу до даних обліку? _(походження: лід)_
  3. [ ] Вимоги до захисту даних і кібербезпеки для сервісу, що керує енергообладнанням клієнтів? _(походження: лід)_
- **Потрібно від редактора:** який досвід інтеграції з Deye Cloud (стабільність API, ліміти, умови доступу) — це внутрішнє знання команди.
