# Ціни хмарних API LLM у часі

Як змінювалася ціна хмарного API за фіксований рівень якості. Для локального розгортання це
тиск із протилежного боку: що дешевший токен у хмарі, то слабший аргумент вартості. Зібрано
у brief'і [[B-003]] (підпитання 5), перевірено критиком 2026-10-08: усі сторінки ok.

## Що знаємо
- Найнижча ціна API за якість рівня GPT-3.5 впала з 20,00 до 0,07 USD за мільйон токенів
  між листопадом 2022 і жовтнем 2024 — понад 280 разів [[E-B003-5-04]] (B, 2024-10).
- За Epoch AI, ціна за фіксований рівень якості падає в 9–900 разів на рік залежно від
  порога; для рівня GPT-4 — у 40 разів [[E-B003-5-10]] (B, 2025-02, середня).
- Найнижча ціна за якість рівня GPT-4 впала з 37,50 USD за мільйон токенів у березні 2023 до
  0,18 USD у лютому 2025 [[E-B003-5-11]] (B, 2025-02, середня).
- Ціна за якість рівня GPT-3 впала з 60 USD (листопад 2021) до 0,07 USD (жовтень 2024); із
  липня 2023 по вересень 2024 найдешевшими для цього порога були моделі Llama в сторонніх
  провайдерів [[E-B003-5-12]] (B, 2024-10, середня).
- Залізо для AI фіксованої продуктивності дешевшає на 30% щороку, а його енергоефективність
  зростає на 40% щороку [[E-B003-5-05]] (B, 2024).

## Протиріччя
- Не знайдено.

## Що не знаємо
- Ціни API після лютого 2025: сторінку Epoch AI з оновленим рядом не відкрито.
- Незалежного порівняння вартості токена on-prem і через API немає; є лише розрахунок
  окупності в документі продавця заліза (Lenovo), не оформлений доказом.
