# Claude Code і Agent SDK як платформа для агентних систем

## Що знаємо
- Субагент стартує з чистим ізольованим контекстом і повертає лише підсумок
  [[E-B002-6-01]]; ліміти: глибина спавну 3, паралельність 20, обидва конфігуровні
  [[E-B002-6-02]] (офіційна документація, без дати).
- Routines виконуються без запиту дозволу, людина перевіряє постфактум
  [[E-B002-6-03]]; Managed Agents API: cron-подібні deployments і $-бюджет сесії
  [[E-B002-6-04]]; ціна $0,08 за session-hour + токени + $10/1000 пошуків
  [[E-B002-6-07]] (B; інший блог називає $0,25, не оформлено).
- Hooks блокують дію детерміновано через exit-код, незалежно від рішення моделі
  [[E-B002-6-08]]; CLAUDE.md і memory — контекст, не enforced-конфігурація
  [[E-B002-6-10]]; skills вантажаться у два етапи [[E-B002-6-09]].
- Anthropic Research: lead Opus + 3–5 паралельних Sonnet-субагентів [[E-B002-6-05]];
  ≈ 15× токенів проти чату, +90,2 % якості [[E-B002-6-06]] (C).
- Опублікованих цифр вартості й часу нічного дослідницького пайплайну на Agent SDK не
  знайдено [[E-B002-6-11]].
- Наш власний досвід: librarian на haiku зупинявся на ліміті 30 ходів при 21+ сторінках;
  з вужчим промптом упорався за 5 викликів (docs/retro-2026-09-09.md). Гейт «red team
  перед writer» реалізовано як PreToolUse hook (scripts/hooks/redteam-gate.mjs).
