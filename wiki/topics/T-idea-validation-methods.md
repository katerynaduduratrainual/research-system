# Методики валідації та відбору ідей: гейти, скоркарди, TAM

## Що знаємо
- Stage-Gate Купера: 5 стадій і 5 гейтів, рішення go / kill / hold / recycle від
  «gatekeepers» [[E-B002-4-01]] (B; сайт вендора методу, без дати).
- Lean Startup: Build-Measure-Learn, MVP, рішення pivot / persevere замість формального
  kill-гейту [[E-B002-4-02]] (B, 2011).
- Disciplined Entrepreneurship Олета: 24 кроки без формальних kill-гейтів
  [[E-B002-4-05]] (B, low).
- Скоркарди: RICE Intercom без kill-порогу [[E-B002-4-03]]; scorecard Пейна дає
  діапазони ваг (команда 0–30 %, розмір можливості 0–25 %) і призначений для оцінки
  вартості pre-revenue стартапу, не для скринінгу ідей [[E-B002-4-04]] (B).
- BCG заявляє 66 % success rate венчур-студій проти 20–30 % у VC/CVC [[E-B002-4-06]]
  (B; самозвіт про власну послугу, «success» не визначено).
- Bottom-up TAM у VC-практиці: клієнти в ICP × середній дохід на клієнта
  [[E-B002-4-09]] (B); офіційної статті a16z чи YC саме про це не знайдено
  [[E-B002-4-10]].
- AI-валідатори ідей: ValidatorAI цитує лише власні внутрішні дані, без зовнішніх
  джерел [[E-B002-4-07]]; огляд третьої сторони: $15–55/міс [[E-B002-4-08]] (C).
- Методологія доказової медицини: GRADE оцінює впевненість для сукупності доказів через
  inconsistency / indirectness / imprecision, PRISMA вимагає протокол пошуку
  [[E-B002-R-03]]; Elicit використовує подвійний незалежний витяг чисел
  [[E-B002-R-02]].

## Протиріччя
- [[E-B002-4-07]] vs [[E-B002-4-08]] — офіційний сайт ValidatorAI показує лише
  безкоштовний рівень, огляд згадує PRO $25/міс.

## Що не знаємо
- Деталі 24 кроків Олета (критерії й докази по кроках) поза книгою.
- Funnel-цифри BCG: ідеї на вході → венчури на виході, час на стадію.
