# Fronius: локальний Solar API (JSON) лише читає дані; хмарний Solar.web Query API платний і описаний як обмін даними; керування — через Modbus

## Контекст
Сторінка Solar API (JSON) [[S-ec8c98b8]]: інтерфейс дає застосункам читати дані з інвертора по мережі (потужність, напруга, струм, дані Smart Meter, Ohmpilot); функцій запису не названо. Сторінка Solar.web Query API [[S-6f766f53]]: SWQAPI — «chargeable programming interface» для обміну даними між клієнтським застосунком і Solar.web; команд керування не згадано. Обидві сторінки перелічують Modbus TCP і Modbus RTU (SunSpec) як окремі відкриті інтерфейси. Що саме Modbus TCP дозволяє керувати батареєю (примусовий заряд/розряд, ліміти) — офіційну документацію Fronius (PDF-інструкції) відкрити не вдалося (Cloudflare/HTML замість PDF); є лише форумні описи (D), тому тут не стверджується. Чи має Fronius хмарне керування розкладом — документацію не знайдено.

## Цитата
> The Solar API is an open REST API that enables applications to read data directly from the inverter via the network.
