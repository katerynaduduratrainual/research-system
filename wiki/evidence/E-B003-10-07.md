# Доказів експорту/API для структурованих даних місій Mission Control не знайдено

## Метод пошуку
Перевірено (15.09.2026): (1) офіційна вікі DELTA, українська й англійська
версії ([[S-b22e857a]], [[S-1d332fef]]) — розділ «Ключові сервіси» називає
зовнішні інтеграції системи в цілому (постачальники супутникових знімків,
радари, GPS-трекери, оператори супутників, чат-боти, «інтерфейси обміну
даними НАТО»), але без деталей про формат чи доступ саме до даних місій
Mission Control; окремого розділу про API чи експорт немає в жодній із
двох версій вікі. (2) Обидва пресрелізи МО про запуск і піврічні підсумки
Mission Control ([[S-6585043d]], [[S-b2d17e34]]) — жодного слова про API,
експорт, інтеграцію із зовнішніми системами чи формати файлів. (3) Пошук
«DELTA Mission Control API інтеграція дані експорт» — результати
нерелевантні (загальні статті про ETL/delta-синхронізацію даних у SAP та
подібних системах, не про українську DELTA). (4) Пошук про
взаємосумісність DELTA з НАТО (CWIX24, формати NATO Vector Graphics і MIP)
дав релевантні заголовки (NATO ACT, Jane's, Kyiv Post — за їхніми
описами DELTA обмінюється ситуативною картиною із системами НАТО у двох
стандартних форматах), але це про ситуативну обізнаність/карту загалом,
не підтверджено окремо для об'єкта «місія» Mission Control, і
першоджерело NATO ACT (act.nato.int) віддало 403 при прямому читанні —
тому в доказ не заноситься (evidence must not rest on a blocked source).
