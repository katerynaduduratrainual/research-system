# Deep-research агенти OpenAI й Gemini вигадують 3.5-13.3% URL-цитат; на 113 цитат/запит проти 3-24 у пошукових LLM

## Контекст
Дослідження перевірило 10 моделей/агентів трьох вендорів (Google, OpenAI,
Anthropic), включно з gemini-2.5-pro-deepresearch та openai-deepresearch, на
бенчмарку DRBench. Кожен нерозв'язний URL перевірявся через Wayback Machine
API: якщо снепшоту немає в жодному часовому штампі — URL класифікується як
вигаданий (галюцинація), інакше — «лінк-рот» (посилання померло, але існувало).

Результати по конкретних продуктах:
- gemini-2.5-pro-deepresearch: 13.3% вигаданих, 18.5% нерозв'язних загалом
- openai-deepresearch: 3.5% вигаданих, 10.1% нерозв'язних загалом
- claude-3-5-sonnet-with-search (не deep-research режим, для порівняння):
  3.0% вигаданих, 7.8% нерозв'язних
- gpt-4.1 (звичайна модель з пошуком, для порівняння): 5.4% вигаданих і
  нерозв'язних

Deep-research агенти в середньому наводять значно більше цитат на запит
(113.1), ніж пошуково-доповнені LLM (3.0-24.3), і мають вищий пул-рівень
галюцинацій — 10.7% [10.2, 11.2] проти 4.8% [4.3, 5.2] у моделей з пошуком.

## Метод (тільки для type: estimate)
Не estimate — прямий підрахунок частки URL, класифікованих як вигадані/
нерозв'язні, на вибірці запитів бенчмарку DRBench; довірчі інтервали наведені
авторами.

## Цитата
> "Hallucinated URL rates range from 3% to 13%, with 5–18% non-resolving overall."

## Нотатки
Це найбільш пряма й незалежна оцінка достовірності цитат для конкретних
комерційних deep-research продуктів, знайдена в межах бюджету. Релевантно
також скауту №5 (adversarial review / провенанс) — лишити цей висновок йому
для загального аналізу вигаданих цитат поза продуктовим контекстом.
