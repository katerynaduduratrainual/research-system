# МАГАТЕ вимагає data diode / односпрямований канал для найкритичніших (рівень 1) систем АСУ ТП АЕС

## Контекст
IAEA Nuclear Security Series No. 17-T (Rev. 1), Annex III (приклад застосування
комп'ютерних рівнів безпеки і зон), параграф III–10: системи, що виконують
функцію запобігання аварійним умовам (напр. система захисту реактора),
належать до найвищого рівня комп'ютерної безпеки (level 1); логічний доступ до
них контролюється саме через відмовостійкий односпрямований канал передавання
даних (data diode). Узгоджується з таблицею III–1 того самого документа: для
системи захисту реактора (CSL 1) прямо вказано «Dedicated internal network
decoupled using data diode» і «No external network connectivity».

## Цитата
> "logical access can be controlled through a fail‑secure, unidirectional data communication pathway (e.g. a data diode)"

## Верифікація
2026-09-15 — ok: цитата дослівна, знайдена в IAEA NSS 17-T (Rev. 1), п. III–10.
Таблиця III–1 (Annex III) для системи захисту реактора (CSL 1) прямо вказує
«Dedicated internal network decoupled using data diode» і «No external network
connectivity» — узгоджується з формулюванням claim. П. III–10 містить
обов'язкове формулювання («needs to be strictly controlled»), а data diode
наведено як метод «в accordance with the guidance in this publication», тому
слово «вимагає» виправдане.

## Нотатки
Пряма вимога первинного документа міжнародного регулятора, високий рівень
впевненості. Узгоджується з NIST щодо того самого механізму — [[E-B003-6-05]].
