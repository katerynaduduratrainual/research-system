# Kimi-Researcher — одноагентна система на end-to-end RL, ~23 кроки й 200+ URL за задачу, без участі людини

## Контекст
Профіль продукту (Moonshot AI Kimi-Researcher):
- (а) план/кларифікація: агент сам генерує think/action на кожному кроці;
  окремого кроку кларифікації з людиною чи затвердження плану офіційна
  сторінка не описує.
- (б) паралелізм: один агент, натренований наскрізним RL; має паралельний
  внутрішній пошуковий інструмент, текстовий браузер і інструмент коду; в
  середньому 23 кроки міркування і 200+ відвіданих URL на задачу.
- (в) участь людини: офіційний опис не згадує жодних точок втручання людини
  під час тренування чи інференсу.
- (г) провенанс/цитати: агент «крос-перевіряє інформацію перед відповіддю» і
  розрізняє переклади від оригінальних текстів при суперечливих джерелах;
  конкретний формат цитування в кінцевому звіті не описано на цій сторінці.
- (ж) evals: заявлені власні результати — Pass@1 26.9% (з 8.6% на старті) і
  Pass@4 40.17% на Humanity's Last Exam; 69% pass@1 на xbench-DeepSearch.
- (з) вартість/час: обчислювальне навантаження зростає при довгих
  траєкторіях (можливо 70+ пошуків за прогін); ціна для зовнішніх
  користувачів на цій сторінці не вказана.
- (и) open/closed: закритий сервіс Moonshot AI (сама модель Kimi K2/K3 —
  окремо, відкрита; Kimi-Researcher як продукт — ні).

## Цитата
> "a parallel, real-time internal search tool; a text-based browser tool for interactive web tasks; and a coding tool for automated code execution"

## Нотатки
Числа продуктивності (HLE, xbench) — самозаявлені вендором, довіра до них
низька без незалежного підтвердження; в незалежному DeepResearch Bench
(E-B002-1-08) Kimi-Researcher не потрапляє до наведеної таблиці.
