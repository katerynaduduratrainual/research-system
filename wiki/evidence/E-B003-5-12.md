# За Epoch AI, ціна API за якість рівня GPT-3 впала з 60 USD за мільйон токенів (листопад 2021) до 0,07 USD (жовтень 2024); із липня 2023 по вересень 2024 найдешевшими для цього порога якості були моделі Llama

## Контекст
Таблиця «Lowest inference prices at fixed performance» на сторінці Data Insight Epoch AI, рядки бенчмарку MMLU з порогом «GPT-3 [43.9, 100]». Ряд повністю (модель, дата, USD за 1 млн токенів): GPT-3, 2021-11-20 — 60,00; GPT-3, 2022-09-01 — 20,00; GPT-3.5 Turbo, 2023-03-06 — 2,00; Llama-2-Chat-13B, 2023-07-18 — 0,56; Llama 2-7B, 2023-12-01 — 0,20; Llama 2-7B, 2024-04-14 — 0,13; Llama-3.1-Instruct-8B, 2024-07-23 — 0,10; Llama-3.2-Instruct-3B, 2024-09-24 — 0,08; Gemini-1.5-Flash-8B, 2024-10-03 — 0,07. П'ять із дев'яти точок ряду, з липня 2023 по вересень 2024, — моделі Meta Llama; за методом джерела, для них узято медіану цін сторонніх API-провайдерів, бо власного API в Meta немає. Ціни GPT-3, GPT-3.5 і Llama 2 — з власної бази Epoch AI, решта — з Artificial Analysis. Метод — [[E-B003-5-10]]; ряд для рівня GPT-4 — [[E-B003-5-11]].

## Верифікація
2026-10-08 — ok: усі дев'ять рядків порога «GPT-3 [43.9, 100]» бенчмарку MMLU збігаються з «Контекстом»: від $60.00 (2021-11-20) до $0.07 (2024-10-03, Gemini-1.5-Flash-8B). Уточнення до періоду: моделі Llama найдешевші в ряді з 2023-07-18 по 2024-09-24 (п'ять точок); у березні 2023 найдешевшою була GPT-3.5 Turbo, з 3 жовтня 2024 — Gemini-1.5-Flash-8B. Тому «у 2023–2024» точніше писати як «із липня 2023 по вересень 2024» і лише для цього порога якості. Ціни Llama — медіана цін сторонніх провайдерів, як і сказано в «Контексті».
2026-10-08 — лід: період у claim звужено до «із липня 2023 по вересень 2024» за уточненням критика (verify B-003/5).
