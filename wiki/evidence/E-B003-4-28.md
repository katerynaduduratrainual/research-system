# За даними NVIDIA, вбудований Jetson AGX Thor генерує 41,3 токена за секунду на Llama 3.1 8B, 61 на Qwen 3 30B-A3B і 4,7 на Llama 3.3 70B за одного запиту

## Контекст
Таблиця «NVIDIA Jetson AGX Thor Benchmarking Results» на сторінці Jetson Benchmarks (NVIDIA Developer). Токени за секунду при 1 / 8 одночасних запитах: Llama 3.1 8B — 41,3 / 150,8; Llama 3.3 70B — 4,7 / 12,6; Qwen 3 30B-A3B — 61 / 226,4; Qwen 3 32B — 13,19 / 79,1; Deepseek R1 7B — 41,32 / 304,8; Deepseek R1 32B — 13,31 / 82,6; візуально-мовні: Qwen2.5-VL 3B — 71,7 / 356,86; Qwen2.5-VL 7B — 45 / 252. Умови: Jetson AGX Thor Developer Kit, JetPack 7.0, CUDA 13.0, TensorRT 10.13, рушій vLLM, довжина входу 2048 і виходу 128 токенів. Рядок таблиці «клас заліза → розмір моделі → швидкість»: вбудований обчислювач. Квантизації моделей, обсягу пам'яті й ціни пристрою сторінка не вказує. Пояснення скаута, не джерела: позначення «A3B» у назві Qwen 3 30B-A3B означає ≈3 млрд активних параметрів (модель MoE, див. [[E-B003-4-19]]), чим можна пояснити, що вона швидша за щільну 8B.

## Цитата
> LLM and VLM benchmarks were performed using VLLM with ISL/OSL as 2048/128.

## Нотатки
Самозаявлено: вимірювання виробника пристрою, джерело grade C — low. Дати на сторінці немає; рік 2025 виведено з версії JetPack 7.0. Незалежного вимірювання для Jetson скаут у межах бюджету не зібрав. Для молодших Jetson (Orin Nano) на цій сторінці чисел LLM немає.
