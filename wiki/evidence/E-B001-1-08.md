# КП YASNO «Базова-А»: ціна = ЦРДН × Кі (1,04) + Р (ОСР) + Т (ОСП) + Цп (0,10 грн/кВт·год), без ПДВ

## Контекст
Розділ 2 КП ТОВ «ЯСНО+» «Базова-А» (версія 08/2025). Кі = 1,04 — коефіцієнт прогнозних витрат постачальника на РДН, ВДР, балансуючому ринку; Р — тариф ОСР на класі напруги; Т — тариф ОСП; Цп — ціна додаткових послуг 0,10 грн/кВт·год. ПДВ обліковується окремо. Тобто рахунок бізнесу = енергія (РДН + націнка через Кі) + розподіл + передача + сервісна надбавка, плюс ПДВ 20% зверху (ставку ПДВ у КП не названо).

## Цитата
> Ці = ЦРДН × Кі + Р + Т + Цп
