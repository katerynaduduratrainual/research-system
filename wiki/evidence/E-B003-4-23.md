# За Lenovo (червень 2026), сервер із 2 GPU RTX PRO 6000 коштує ≈68 тис. USD, з 8 H200 — ≈398 тис., з 8 B300 — ≈786 тис.

## Контекст
Розділ «System Pricing» документа Lenovo Press LP2368 (оновлено 24.07.2026). Ціни з внутрішнього конфігуратора Lenovo, «usual sale price to the customer», USD: Config A, ThinkSystem SR650i V4, 2x RTX PRO 6000 — 68 010,96; Config E, SR650a V4, 4x L40S — 113 186,50; Config B, SR675 V3, 8x H200 — 397 801,60; Config C, SR680a V3, 8x B200 — 550 475,10; Config D, SR680a V4, 8x B300 — 785 606,50; Config F, SR650 V4, лише CPU (Intel Xeon 6) — 82 265,40. Рядки таблиці «клас заліза → ціна»: один GPU-сервер. Поточні витрати за розрахунком Lenovo для Config B — 9,80 USD за годину (обслуговування 12% вартості на рік, електрика й охолодження, розміщення в дата-центрі). Повного складу конфігурацій (процесори, пам'ять, диски, мережа) документ не наводить.
