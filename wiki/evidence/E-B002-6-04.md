# Claude Managed Agents API підтримує cron-подібні scheduled deployments і session budget у $

## Контекст
Claude Managed Agents (Claude Platform API, окремо від Claude Code CLI/
Routines) — керований "harness" для довготривалих асинхронних агентних
сесій: bash, файлові операції, web search/fetch, MCP-сервери, вбудований
prompt caching і compaction. Явно підтримує "scheduled execution: Recurring
agent runs on a cron schedule through scheduled deployments" — це саме той
рівень API, на якому можна побудувати застосунок з нічними скаутами й
чергою, не через інтерактивний CLI. Session budget — доларова стеля на
токени/пошуки/час однієї сесії. Станом на доступ — публічна бета під
beta-заголовком `managed-agents-2026-04-01`.
Профіль: автоматизує — повний агентний цикл (bash/файли/веб/MCP) у
хмарному sandbox, stateful між сесіями; людина в циклі — steer/interrupt
під час сесії через events, або огляд після; бюджети — session budget у $
на сесію (токени+пошуки+час); опубліковані цифри вартості — див.
[[E-B002-6-07]]; ліміти — API в стані beta, поведінка може змінюватись.

## Нотатки
Це найближчий готовий будівельний блок під v1 "нічні скаути + черга +
дашборд" з docs/vision.md: не треба самим писати cron/scheduler чи
sandboxing — Managed Agents дає це на рівні API, а власний дашборд/черга
будується поверх events/session-стану.
