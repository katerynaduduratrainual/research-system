# Субагент Claude Code стартує з чистим ізольованим контекстом і повертає лише підсумок

## Контекст
Офіційна документація Claude Code про субагентів. Субагент не бачить історію
батьківської розмови, не бачить вже викликані skills чи вже прочитані файли —
йому потрібно передати весь контекст у промпті делегування. Завантажується:
власний системний промпт, повідомлення-делегування, CLAUDE.md, git-статус,
preloaded skills. Не завантажується: історія розмови, output style, auto
memory батьківської сесії. Це і є профіль автоматизації "скаута" в нашій
термінології: людина не бере участі під час роботи субагента, лише формулює
завдання наперед і читає підсумок після.
Профіль: автоматизує — паралельний side-task (пошук, аналіз) в окремому
контексті; людина в циклі — лише до старту (формулює промпт делегування) і
після (читає summary); бюджет токенів — вручну через maxTurns на субагента
(див. [[E-B002-6-02]]); опубліковані цифри вартості/часу — невідомо (немає в
цій довідці); зустрінуті ліміти — див. [[E-B002-6-02]].

## Цитата
> "Each subagent starts with a fresh, isolated context window. It doesn't see your conversation history, the skills you've already invoked, or the files Claude has already read."

окремим контекстом, що повертає лише ID доказів). Немає протиріч.
