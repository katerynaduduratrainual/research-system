# Формати логів ArduPilot (dataflash, tlog) задокументовані офіційно й читаються сторонніми інструментами

## Контекст
Офіційна документація ArduPilot описує два типи логів: dataflash-логи (`.bin`/`.log`,
записуються на автопілоті) та телеметрійні tlog (записуються наземною станцією через
MAVLink). Структура повідомлень (ATT, CTUN, GPS тощо) задокументована окремо на
довідковій сторінці "Onboard Message Log Messages". Кілька сторонніх інструментів
(MAVExplorer, вебзастосунки, Mission Planner) можуть читати ці формати.

## Цитата
> "This utility provides an easy to use viewer for ArduPilot dataflash and telemetry logs."

## Верифікація
2026-09-11 — ❌ failed: цитати "This utility provides an easy to use viewer for
ArduPilot dataflash and telemetry logs." немає на сторінці-джерелі. Сторінка натомість

Web-based tools" та посилання на "Onboard Message Log Messages" для форматів. Сама теза

текстом сторінки — цитату слід замінити. Confidence знижено high → low.

які обидва використовують MAVLink) не потребує реверс-інжинірингу закритого
протоколу — специфікація публічна. Це НЕ стосується DJI (закритий формат логів) —
