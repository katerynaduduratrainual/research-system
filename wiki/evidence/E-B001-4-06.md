# Growatt OpenAPI (OAuth 2.0, токен через OSS-акаунт) має інтерфейси налаштування параметрів накопичувачів і читання/запису часових періодів VPP

## Контекст
Розділ «Open Platform Overview» документації Growatt OpenAPI: RESTful-сервіс для автентифікованих користувачів, механізм OAuth 2.0; щоб отримати токен, треба завести OSS-акаунт Growatt (регіональні сервери oss.growatt.com для Європи та світу, oss-us, oss-au, oss-cn) і подати заявку. Токен «Permanent (tentative)», анулюється, якщо користувач відкликає авторизацію. Перелік сторінок документації містить «Energy storage machine parameter setting», «SPH parameter settings», «Spa parameter settings», «Inverter parameter setting», «Get machine SOC value (VPP)» і «Read and set VPP time period parameters (VPP)». Вміст сторінок налаштувань (які саме параметри, чи є розклад заряду від мережі) не відкривали. Ліміти частоти викликів і платність на оглядовій сторінці не названі. Документ розміщено на ShowDoc, без дати.

## Цитата
> The platform interface is based on the http(s) protocol and uses the OAuth2.0 authentication mechanism.
