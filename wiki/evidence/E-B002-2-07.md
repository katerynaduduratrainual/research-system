# ByteDance DeerFlow 2.0: гнучкий harness з прогресивним завантаженням skills замість фіксованих ролей, MIT

## Контекст
Офіційний репозиторій bytedance/deer-flow (README + GitHub API, перевірено
2026-09-11); версія 2.0 — переписаний з нуля рушій, вийшла ~28 лютого 2026.
Опис за фіксованими вимірами:

- **(а) план/brief**: підтримується "plan mode" з явним оглядом завдання перед
  виконанням; сесії підтримують постановку цілі й ручне стиснення контексту.
- **(б) паралелізм/ізоляція**: замість жорстких ролей (Coordinator/Planner/
  Researcher/Coder/Reporter) lead-агент динамічно делегує subagents через
  інструмент `task`; ізоляція забезпечується "прогресивним завантаженням
  skills" (можливості підвантажуються лише коли потрібні) + пісочниці
  (Local/Docker/Kubernetes/E2B) як межі виконання; skill-каталог працює як
  "package boundary".
- **(в) участь людини**: підтримуються огляд плану й фідбек користувача під
  час виконання; конкретних затверджувальних checkpoint-ів (approval gates) у
  прочитаній документації не деталізовано.
- **(г) провенанс/цитати**: трекінг через `deerflow_trace_id`, delivery
  receipts на кожне завершення прогону, інтеграція з Langfuse/LangSmith для
  спостережуваності; спеціального механізму цитування джерел у звіті (як у
  GPT Researcher) в описі немає — невідомо.
- **(д) накопичення між сесіями**: пам'ять і файлова система входять до
  "harness" за замовчуванням, але деталі персистентності між окремими
  сесіями не наведені в прочитаному матеріалі — невідомо.
- **(е) протиріччя, (є) adversarial review**: не описані — невідомо.
- **(ж) evals**: у документації немає опублікованих benchmark-результатів —
  доказів не знайдено (перевірено README проєкту).
- **(з) вартість/час**: бюджети токенів/subagents конфігуруються
  (`subagents.max_total_per_run`), конкретних цифр вартості немає.
- **(и) ліцензія/активність**: MIT; 82 270 зірок; `pushed_at` 2026-09-11
  (GitHub API) — штоденна активність, #1 у GitHub Trending ~28.02.2026.
