# GGUF — формат файлу для зберігання моделей під інференс у GGML і сумісних виконавцях; вся потрібна інформація міститься в одному файлі.

## Контекст
Специфікація GGUF, формат версії 3. Файл містить заголовок, метадані ключ-значення (гіперпараметри, архітектура, токенізатор), дескриптори тензорів і ваги. Цілі дизайну: один файл, підтримка mmap, розширюваність. Типи квантизації перелічено в enum (Q4_0, Q4_K тощо).

## Цитата
> GGUF is a file format for storing models for inference with GGML and executors based on GGML.

## Верифікація
2026-11-09 — inexact: перша частина дослівно є в специфікації, але «вся потрібна інформація міститься в одному файлі» стирає межу: «Single-file deployment» і «Full information» стоять у переліку бажаних властивостей («The following features are desired») і стосуються інформації для завантаження моделі, а специфікація водночас описує поділ на шарди («split into multiple shards») і окремі sidecar-файли mmproj та mtp. Правильне формулювання: «Серед цілей дизайну — розгортання одним файлом і зберігання всієї інформації для завантаження моделі у файлі; водночас специфікація передбачає шарди і sidecar-файли». Дата останнього коміту 2026-11-08 підтверджена через GitHub API.
