# DGX Spark: самозаявлена пропускна здатність QLoRA-донавчання (NVIDIA)

## Контекст
Той самий офіційний блог NVIDIA ([[E-B003-4-06]]), розділ про donavчання:
Llama 3.3 70B QLoRA — "5,079.4 tokens per second"; для менших моделей також
наведено Llama 3.1 8B (LoRA) "53,658 tokens per second" і Qwen3 14B (inference)
"5,929 tokens/sec prompt processing, 22.71 tokens/sec generation". Прямого
числа для моделі класу 27-32B при QLoRA на сторінці немає — найближчий за
розміром приклад (70B) значно більший за цільовий клас.

Порівняльні числа в Контексті теж підтверджені: Llama 3.1 8B LoRA — 53,657.6 tok/s (округлено джерелом до 53,658 у зведенні статті), Qwen3 14B — 5928.95 tok/s prompt processing / 22.71 tok/s generation (округлено до 5,929/22.71). Підтверджено відсутність на сторінці прямого числа для класу 27-32B при QLoRA. Нотатки явно містять «Самозаявлено вендором» — вимога підпитання виконана. ## Нотатки
Самозаявлено вендором — це маркетинговий/технічний блог NVIDIA про власний
продукт, а не незалежний тест, і про продуктивність (не про ліміт/ціну), тому
