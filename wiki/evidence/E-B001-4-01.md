# Deye Cloud OpenAPI дає стороннім розробникам команду керування пристроєм «Set Time of Use» і перевірку результату команди за orderId

## Контекст
Розділ Quick Start офіційного порталу developer.deyecloud.com (оновлено 31.03.2025): «Create a DeyeCloud Application» (реєстрація акаунта Deye Cloud), «Obtain Access Token» окремо для Personal User і Business Member, далі «Commit the command to control the device» з підрозділами «Set Time of Use of the Device» та «Obtain the command result based on orderId». Є окремі розділи API Documentation і MCP Documentation. Тобто керування розкладом заряду/розряду (TOU) через хмару — штатна функція API; доступ через власний акаунт або бізнес-акаунт (інсталятор), без ознак окремої партнерської програми в меню. Текст видобуто з JS-бандла SPA; повний текст розділів (параметри TOU) не прочитано. Підтверджує технічну основу [[E-ING-20261006-01]].
