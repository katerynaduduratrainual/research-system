# Чим ближчий досвід до галузі стартапу, тим вищий шанс на топ-зростання

## Контекст
Azoulay та ін., NBER WP 24489 (2018), розділ V.A, Table 6, панелі A–C (2-, 4-, 6-значні коди NAICS).
Для топ-0,1 % фірм: без досвіду у 2-digit галузі — 0,11 %; з ≥3 роками досвіду — 0,22 % (2-digit),
0,24 % (4-digit), 0,26 % (6-digit). У вступі автори пишуть про зростання success rates «up to 125%».
Висновок авторів: результати відкидають ідею, що прихід ззовні галузі прогнозує надзвичайний успіх;
можлива креативна перевага аутсайдерів, «if so», перекривається іншими силами.

## Цитата
> success rates that rise from 0.22% (2-digit NAICS experience) to 0.24% (4-digit NAICS experience) to 0.26% (6-digit NAICS experience)

## Верифікація
2026-10-05 — ok: цитата дослівна; 0,11 % / 0,22 % / 0,24 % / 0,26 % збігаються з текстом і Table 6. Уточнення: 0,11 % — база для 2-digit; у панелях B і C (4- і 6-digit) база без досвіду — 0,12 %; автори самі порівнюють з 0,11 %. Пропозиція щодо grade — як у [[E-B004-1-04]].

## Нотатки
Базовий рівень вищий за 0,1 %, бо поріг визначено на рівні фірми, а рахунок — на рівні засновника
(виноска 37). Числа з WP; опублікована версія (AER: Insights 2020) не відкривалась.
