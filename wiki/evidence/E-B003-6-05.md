# Artificial Analysis дає безкоштовний API (JSON, 1000 запитів на добу, з обов'язковим посиланням) із балами якості, швидкістю й цінами моделей; повніші дані у комерційному API

## Контекст
Сторінка документації «Artificial Analysis API Documentation (Free API)». Доступ — після
реєстрації на платформі й створення ключа; запит `GET /api/v2/data/llms/models` із
заголовком `x-api-key` повертає JSON зі списком моделей: ідентифікатор, розробник, бали
оцінювань, ціна за мільйон токенів, швидкість і затримка. Окремі ендпоінти — для моделей
зображень, відео й мовлення. Про комерційний API сказано лише, що його документацію дають
партнерам окремо; ціни не названо. Як часто оновлюються дані, документація не каже.

Що тут про локальні моделі: на сторінці методології (`artificialanalysis.ai/methodology`,
відкрита скаутом) сказано, що вимірювання швидкості відображають те, що бачать клієнти
сервісів inference, і не показують максимум конкретного заліза: «our performance benchmarking
measures the end-to-end performance experienced by customers of AI inference services and
systems»; там само — «We benchmark both proprietary and open weights models» і окремий розділ
«Small Language Model Intelligence». Тобто якість відкритих і малих моделей тут є, а швидкість
на ноутбуці чи власному сервері — ні. Панелі відкритих моделей за розміром уже описані в
[[S-f280d35d]] (факти — [[E-B003-4-05]], [[E-B003-4-08]], [[E-B003-4-09]]).

## Цитата
> Our free API is focused on sharing primary metrics from our independent benchmarks of models. … The API is rate-limited to 1,000 requests per day.

## Верифікація
2026-10-08 — ok (жива сторінка; адреса `/documentation` тепер переспрямовує з кодом 308 на `/api-reference`, зміст той самий): цитата дослівно (два речення з блоку «Free Artificial Analysis Data API»). Підтверджено: «We offer a free API focused on model benchmarks and a commercial API with more comprehensive data. Commercial API documentation is available to partners separately»; «Attribution is required for all use of our free API»; ліміт 1,000 запитів на добу; приклад відповіді — JSON із полями `evaluations`, `pricing`, `median_output_tokens_per_second`, `median_time_to_first_token_seconds`. Доступ потребує облікового запису й ключа (є в «Контексті», у claim не винесено). Дати сторінки й частоти оновлення даних документація не називає; цін комерційного API немає. Сторінку методології з «Контексту» критик не відкривав. Grade B (документація постачальника про власний продукт: доступ, формат, ліміти) відповідає AGENTS.md.

## Нотатки
Умови доступу — з офіційної документації, перевірено прямим читанням сторінки. Сам API
скаут не викликав (потрібна реєстрація), тож перелік полів — за прикладом відповіді в
документації. «Independent» — самоназва компанії.
