# Managed Agents: $0.08 за session-hour + стандартні ставки токенів + $10/1000 web-пошуків

## Контекст
Незалежний розбір ціноутворення Claude Managed Agents (FinOps-блог), що
цитує офіційну модель білінгу Anthropic: два виміри — токени (за
стандартними ставками Claude API, наприклад Opus 4.6 $5/млн input, $25/млн
output) і час виконання сесії ($0.08 за session-hour, тарифікується до
мілісекунди, накопичується лише поки статус сесії "running", простій під
час очікування не тарифікується). Веб-пошук — окремо, $10/1000 запитів.
Приклад з посту: годинна сесія на Opus 4.6 з 50K input + 15K output токенів
коштує $0.705; з prompt caching на 80% input — $0.525.
Офіційна сторінка platform.claude.com/docs/en/managed-agents/overview
підтверджує модель "два виміри — токени + session runtime" і що
runtime заміняє окрему тарифікацію container-hours, але не показала точну
цифру $0.08 у витягнутому тексті — цифру взято з незалежного джерела, що
посилається на офіційний приклад Anthropic.

## Цитата
> "$0.08 per session-hour, billed to the millisecond"

## Нотатки
Це найконкретніша знайдена цифра вартості "часу прогону" для довготривалого
Claude-агента — пряма підстава для оцінки бюджету нічних скаутів у v1
(вартість = токени сесії + $0.08/год × тривалість + $0.01/пошук). Один
інший блог (Tygart Media, знайдений у пошуку) називав $0.25/session-hour;
джерело нижчого рівня довіри (SEO-блог без деталізованого розрахунку), тому
в порівняння не взято окремою сторінкою — залишено як прогалину.
