# Anthropic Research: lead-agent оркеструє 3–5 паралельних subagents з окремими контекстами, потім CitationAgent додає цитати

## Контекст
Інженерний пост Anthropic (2025-06-13) про внутрішню систему Research: патерн
orchestrator–worker. Опис за фіксованими вимірами brief:

- **(а) план/brief і уточнення**: lead agent сам аналізує запит, формує стратегію
  і зберігає план у Memory, щоб не втратити його при наближенні до ліміту вікна
  контексту (200k токенів); явного кроку уточнення в людини до старту не описано.
- **(б) паралелізм та ізоляція контекстів**: lead spawns 3–5 subagents паралельно,
  кожен зі своїм контекстним вікном; subagents паралельно використовують 3+
  інструменти. Правила масштабування вбудовані в промпт (1 агент/3–10 викликів
  для простих фактів → 10+ subagents для складного дослідження).
- **(в) участь людини**: людські тестувальники шукають edge cases, яких не ловлять
  evals; людина отримує фінальний цитований звіт. Проміжного checkpoint
  затвердження плану людиною в описі немає.
- **(г) провенанс/цитати**: окремий CitationAgent постобробляє документи й звіт,
  щоб знайти конкретні місця для цитат.
- **(д) накопичення між сесіями**: план зберігається в Memory лише для виживання
  в межах одного запуску (проти ліміту контексту); наскрізного накопичення
  знань між різними сесіями/запитами в описі немає.
- **(е) протиріччя** та **(є) adversarial review**: у прочитаному матеріалі не
  описані окремі механізми роботи з протиріччями джерел чи adversarial-перевірки
  (лише CitationAgent як пост-перевірка цитат) — прогалина.
- **(ж) evals**: внутрішній eval + BrowseComp, +90.2% над одноагентним Opus.
- **(з) вартість/час**: агенти ~4× токенів чату, multi-agent ~15× токенів чату;
  −90% часу дослідження для складних запитів.
- **(и) ліцензія**: не застосовується — це закритий продукт Anthropic Research,
  описаний лише через інженерний блог, не open-source репозиторій.

## Цитата
> "A lead agent coordinates the process while delegating to specialized subagents that operate in parallel."
