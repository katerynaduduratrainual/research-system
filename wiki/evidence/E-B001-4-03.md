# Доступ до northbound API Huawei FusionSolar видається окремо на запит через службу Huawei, з обмеженням частоти викликів

## Контекст
Інструкція Huawei v01 (26.12.2019), с. 2: право доступу до northbound API не збігається зі звичайним акаунтом користувача, на нього треба подати окрему заявку; крок 1 — написати на eu_inverter_support@huawei.com, щоб створили openAPI-акаунт для станції. Сторонні застосунки обмежені частотою викликів «раз на хвилину» на той самий інтерфейс; при перевищенні — помилка частоти доступу. Описані інтерфейси лише читають дані (станції, KPI, перелік пристроїв).

Керування батареєю: пошукова видача (запит 2026-10-06) показала, що офіційний «SmartPVMS 24.5.0 Northbound API Reference» (support.huawei.com/enterprise/en/doc/EDOC1100379184/7a471100/control-apis) має розділ Control APIs (завдання заряду/розряду батареї, режим роботи батареї, активна потужність інвертора). Сторінку відкрити не вдалося (Access Denied / порожня), тому цей факт тут не стверджується як доказ — документацію не прочитано.

## Цитата
> The access privilege to the northbound interface API is independent of third-party user accounts, and users must apply for it separately.
