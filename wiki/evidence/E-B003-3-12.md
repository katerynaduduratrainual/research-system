# Tabnine (AI-асистент для програмістів) документує приватне встановлення на власних серверах замовника або у VPC, зокрема в повністю ізольованому (air-gapped) середовищі.

## Контекст
Розділ «Private Installation» офіційної документації Tabnine, прочитаний 2026-10-08.
Названі варіанти: virtual private cloud (VPC) у AWS, GCP чи Azure та on-premises на
власних серверах замовника. Тип продукту для переліку: on-prem інструмент для
програмістів. Вимоги до заліза на цій сторінці не наведені (вона відсилає до окремого
розділу). Покупців, стадію компанії й залучені кошти документація не називає; сторінку
цін (`tabnine.com/pricing/`) відкрити не вдалося (502 двічі).

## Цитата
> Private installations can be deployed in a completely air-gapped environment.
