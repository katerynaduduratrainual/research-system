# Опублікованих цифр вартості/часу саме нічного дослідницького пайплайну на Agent SDK не знайдено

## Контекст
У межах бюджету скаута (12 пошуків, 10 джерел) не знайдено публічної статті
чи репозиторію, що описує вже побудовану й такою, що працює (не тільки
туторіал), систему на кшталт "нічні скаути + черга + дашборд" на Claude
Agent SDK/Managed Agents з конкретними цифрами $ і часу прогону за
тривалий період (тижні/місяці). Знайдені цифри вартості стосуються або
одиничних кодингових сесій (напр. "$13/розробник/день", "$400-1500/міс" —
не про дослідницькі пайплайни), або самого механізму ціноутворення Managed
Agents без реального кейсу нічного дослідницького пайплайну (див.
[[E-B002-6-07]]), або кейсів на іншу тему (Duvo — ціновий моніторинг
постачальників, не дослідницький скаутинг).

## Метод пошуку
Запити: "Claude Agent SDK scheduled tasks nightly agent"; "\"built on\"
\"Claude Agent SDK\" research monitoring pipeline case study cost"; "Claude
Code cost breakdown long running agent tokens dollars blog 2026"; огляд
awesome-claude-code (не відкривався окремо через ліміт бюджету — залишено
як прогалина). Жодного результату з реальними числами саме для research/
monitoring пайплайну не знайдено.

## Нотатки
Сумісно з природою запиту: research/scheduled agents на Claude — новий
(2025-2026, research preview) функціонал; публічні кейс-стаді з довгою
історією експлуатації ще не встигли з'явитись.
