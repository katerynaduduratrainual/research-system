# Відкриті питання

Питання, на які може відповісти лише людина, або які агенти не змогли закрити.
Формат: `- [ ] <brief>/<sq>: <питання>` · закриті — `[x]` з посиланням на доказ.

- [ ] B-001/3: Який реальний середній час проходження шляху грант → тестування → кодифікація → перший контракт через Brave1/DOT-Chain Defence для ПЗ-продукту (не заліза) — офіційні портали (brave1.gov.ua/manufacturers, codification.brave1.tech) не вдалось прочитати напряму (403 / DNS) в межах бюджету скаута, потрібен прямий контакт або повторна спроба доступу.
- [ ] B-001/3: Чи покриває система обліку/документообігу, яку будує АОЗ/ДОТ in-house (E-B001-3-06), рівень окремого борта й техобслуговування, чи лише кількісну логістику постачання — визначає, чи є I-001 конкурентом державної системи чи потенційним постачальником даних до неї.
