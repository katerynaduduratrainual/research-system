# raw/

Незмінні копії джерел. Файл сюди пишеться один раз і ніколи не редагується.
Ім'я: `YYYY-MM-DD-<slug>.md`. Заголовок файлу:

```
---
url: 
title: 
fetched: YYYY-MM-DD
added_by: scout | user
source: S-<hash8>
---
```

Далі — текст джерела як є. Сюди зберігаються лише первинні джерела, які можуть
зникнути (звіти, PDF, офіційна статистика), і все, що додає користувач через `/ingest`.
